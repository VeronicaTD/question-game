# Собери вопрос! 🐯

Интерактивный урок-тренажёр вопросов в Present Simple: `do/does` · `am/is/are` · `can` · `have got`.

Один связный урок из 8 этапов, от узнавания к свободному письму:

1. 🔑 Слова-ключи — where / what / when / how / what time
2. 🔍 Охота за глаголом — найти глагол и назвать его семью
3. ⚡ Speed Sort — вопросы по корзинам (знакомые → новые)
4. 🎁 Have got или do?
5. 🧱 Конструктор — сборка вопроса из блоков
6. 📝 Рабочий лист — дописать вопрос после слова-ключа
7. 🎯 Миссия — построить и задать вопрос вслух
8. 🕵️ Детектив — написать вопрос целиком по ответу

## Запуск

Открыть `index.html` в браузере или локально:

```bash
npm run dev
```
